# Walkthrough: SWAMP-FHAB Field Data App User Manual

I have created a comprehensive user manual for the SWAMP-FHAB Field Data Collection Application. This document covers everything from initial profile setup to advanced administrative functions.

## Key Features Documented
- **User Profile Management**: How to set up and switch between personnel profiles.
- **Data Collection Forms**: Detailed walkthroughs of the Planktonic and Benthic forms, including GPS auto-lookup and photo integration.
- **Visual Identification Tools**: Documentation of the integrated Percent Cover Diagram.
- **Tool Box Utilities**: Explanations for the BloomReport Helper and Chain of Custody generator.
- **Data Management**: How to view, edit, and export historical records.
- **Administration**: Overview of the Station Code Manager and the password-protected Admin Dashboard.
