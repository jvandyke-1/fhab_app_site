# User Manual for SWAMP-FHAB Field Data Collection App

The goal is to create a comprehensive manual that explains the operation and features of the application. I will be using live screenshots from the application running in an Android emulator to illustrate the features.

## User Review Required

- **Emulator Connection**: Please ensure an Android emulator is started and the app is running on it. I will use `adb` to capture screenshots from the emulator.
- **Manual Content**: If there are specific features or "hidden" tips you want emphasized, please let me know.

## Proposed Structure

The manual will be organized into the following sections:

1.  **Introduction**: Overview of the app's purpose (collecting planktonic and benthic field data).
2.  **Getting Started**:
    *   **User Profile Setup**: Explaining why a profile is needed and how to create/select one.
    *   **Main Dashboard**: Overview of the home screen sections (Forms, Tool Box, Resources).
3.  **Data Collection Forms**:
    *   **Planktonic Field Data Sheet**: Walkthrough of the planktonic form.
    *   **Benthic Field Data Sheet**: Walkthrough of the benthic form.
    *   **Combined Site Visit**: Explaining the combined workflow.
    *   **Form Features**: GPS auto-lookup, Station Code validation, Photo attachments, and Field Measurements.
4.  **Managing Records**:
    *   **History & Editing**: How to view, search, and edit saved records.
    *   **Exporting Data**: Exporting to CSV/PDF and sharing.
    *   **Data Cleanup**: Clearing specific form types or resetting the database.
5.  **Tool Box Utilities**:
    *   **BloomReport Helper**: How it assists in autofilling the state web portal.
    *   **Chain of Custody (CoC)**: Generating CoC forms from multiple visits.
6.  **Resource Library**:
    *   Accessing SOPs, Visual Guides, and original PDF sheets.
7.  **Administration & Settings**:
    *   **Station Code Manager**: Managing pre-defined sampling locations.
    *   **Admin Dashboard**: Finalizing and reviewing records before submission.
