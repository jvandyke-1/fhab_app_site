Privacy Policy

Effective Date: July 24, 2024

1. Data Collection

The HAB Bloom Report Bridge extension does not collect, store, or transmit any user data to external servers. It acts solely as a "bridge" to move data from the FHAB Field App to the official California State Water Boards portal.

2. Data Usage

The extension processes the following data types only when explicitly triggered by the user:

  • Personally Identifiable Information: Name and Email for form submission.
  • Location: GPS coordinates for the field visit.
  • Website Content: Field photos and Bloom Report IDs.

3. Data Storage

All data processed by the extension is stored locally in the user's browser storage and is cleared after the reporting process is complete. No data is shared with third parties.

4. Contact

For questions regarding this policy, please contact the application administrator.
